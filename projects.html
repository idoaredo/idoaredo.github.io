AD IAM Hands-On Lab — 2026 · GitHub

A real Active Directory Domain Services environment built from scratch on an Azure Windows Server VM (started 2026-07-20): forest deployment, domain controller promotion, and a structured track of identity administration tasks — user lifecycle (create, unlock, password reset, disable and offboard), OU design, Group Policy fundamentals verified with Group Policy Modeling, and a complete Joiner/Mover/Leaver cycle. Every task is documented in a change-control-style journal with tickets, redacted evidence screenshots, and "what I learned" notes, mapped to the EU regulatory context (DORA, CSSF) that makes IAM discipline mandatory in Luxembourg's financial sector.

Active Directory · Azure · Windows Server · PowerShell · IAM · GPO

AutoPrompt — 2025 · GitHub · Live

A single-file prompt engineering workbench covering five AI modalities: Text, Image, Audio, Video, and Code. Supports 16 models across Claude, GPT-4o, Gemini, Midjourney, DALL-E 3, ElevenLabs, Sora, and others, with per-model capability detection. Includes a multi-agent designer with export to CrewAI, AutoGen, and LangGraph; a social media panel for 8 networks with format-specific aspect ratios and character limits; and prompt frameworks RISEN, RTF, COSTAR, and TRACE. Bilingual PT/EN. Single HTML file — zero external dependencies, fully offline.

HTML · CSS · JavaScript · Prompt Engineering · AI
